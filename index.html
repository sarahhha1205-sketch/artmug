Process

이용 순서

01
문의 · 상담
전달된 주문서를 바탕으로 작업 범위를 논의합니다.
02
주문 · 결제
입금 확인 후 작업을 시작합니다.
03
작업 진행 · 중간 확인
작업 중 중간 결과물을 공유하고, 피드백에 따라 수정합니다.
04
제작 · 파일 전달
작업한 블루프린트 / 와루도 Prop 파일을 전달해 드립니다.
05
원격 세팅
필요 시 작업물을 원격으로 Warudo에 세팅해 드립니다.
06
테스트 · 수정
API 테스트 후 피드백에 따라 작업물을 조정해 드립니다.
07
완료
최종 확인 후 Warudo에서 정상 동작이 확인되면 작업을 마무리합니다.
Notice

주의사항

주문·제작 전 아래 내용을 확인해 주세요.

릴툰 세팅

기본적으로 릴툰 세팅 기반으로 작업됩니다.

자체 제작 프로그램

VTube Studio API는 제가 직접 만든 프로그램으로 동작합니다.
OBS 오버레이 방식뿐 아니라, VTube Studio에 직접 연결해서 캐릭터가 따라다니는 연출도 가능합니다.
세부 연동 방식은 상담을 통해 안내드립니다.

API 소스 변경 가능

모든 API에 사용되는 소스(물건, 사운드, 위치, 속도, 방향 등)는 원하시는 대로 변경 가능합니다.
예를 들어 날아오는 물건의 종류, 효과음, 등장 위치, 이동 속도, 진행 방향 등을 취향에 맞게 커스텀할 수 있습니다.

보유 에셋 활용 가능

이미 가지고 계신 에셋(2D 이미지, 3D 모델링)이 있다면, 해당 에셋을 API에 적용할 수 있습니다.

저작권

커미션으로 제작된 작업물의 저작권은 제작자에게 있습니다.

재판매 · 재배포

제작물의 무단 재판매, 재배포, 양도는 불가합니다.

포트폴리오 사용

작업 결과물, 작업과정은 포트폴리오, SNS, 홍보 자료에 사용될 수 있습니다.
